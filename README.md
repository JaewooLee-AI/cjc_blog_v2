# 🚀 씨제이씨협동조합 AI 블로그 마케팅 자동화 시스템 (PoC)

본 시스템은 씨제이씨협동조합(CJC Cooperative)의 소상공인들과 실무자를 위한 맞춤형 **AI 블로그 SEO 및 자동 포스팅 시스템**입니다. 
대한가발협회 인프라 및 ATUM 3D 두상측정기 기술력 기반으로, 최신 가발/두피 관련 뉴스를 실시간 추적하고 네이버 스마트에디터 ONE 서식에 100% 대응하는 고품질 마케팅 포스팅을 생성합니다.

---

## 🌟 주요 기능 (Key Features)

- **[F-01] 트렌드 키워드 뉴스 자동 수집 및 중복 제거**:
  - 네이버 검색 최적화 키워드(가발, 탈모, 맞춤가발 등) 기반 뉴스 크롤링
  - SQLite URL Hash 기반 O(1) 중복 기사 자동 아카이빙 및 필터링
- **[F-02] 정보성 SEO 원고 생성 & PPL 자동 삽입**:
  - 수집된 기사 맥락을 분석하여 씨제이씨협동조합 Fact DB(ATUM 3D 스캐너, KOTITI 인증, 7~10일 배송 등) PPL 자연스러운 인용
  - 의료법/광고법 준수 검증 (금기어 자동 치환 및 정제)
- **[F-03] 단문 개요 기반 1,500자 브랜드 글 확장**:
  - 핵심 키워드 2~3줄 입력 시 조합 톤앤매너를 입혀 1,500자 포스팅으로 완성
- **[F-04] 네이버 스마트에디터 ONE 안전 전송 (Playwright 기반)**:
  - 네이버 봇 감지(C-Rank / DIA+) 완전 우회 (인간 유사 랜덤 지연 메커니즘)
  - OS 클립보드(CF_HTML / osascript) 바인딩 및 제목/본문 자동 입력
  - **반자동(Semi-Auto) 커스텀 안전 설계**: 자동 입력 완료 후 크롬 브라우저를 띄워두고 대기하여 계정 제재 및 차단 리스크 0% 실현
- **[F-05] 실사 이미지 라이브러리 및 AI 문맥 자동 매칭**:
  - 매장, 제품, 스캐너 실사 이미지 등록 및 관리 (Tab 4)
  - AI가 소제목 문맥과 가장 잘 어울리는 이미지 3~5장 자동 선별 및 배치

## 🚀 빠른 시작 가이드 (Quick Start)

### 1. 환경 설정 및 실행
```bash
# 가상환경 활성화 및 시스템 실행
source venv/bin/activate
streamlit run app.py
```

### 2. 기본 사용 흐름
1. 브라우저에서 `http://localhost:8501/` 접속
2. **`[📰 최신 뉴스 기사 자동 수집]`** 탭에서 키워드 선택 후 기사 수집 실행
3. 수집된 기사 아래 **`[✨ 이 기사로 SEO 원고 작성]`** 클릭
4. **`[🚀 네이버 에디터로 전송 (반자동)]`** 클릭
5. 자동 입력이 완료된 후, 브라우저 화면 우측 상단의 **`[발행]`** 버튼을 **'직접'** 클릭하여 안전하게 포스팅 완료

## ⚙️ 주요 모듈 구조

* `crawler.py`: Google News / RSS 기반 최신 트렌드 기사 수집기
* `db_manager.py`: SQLite 기반 기사 URL 해시 중복 검사 ($O(1)$) 및 로그 관리
* `llm_router.py`: OpenAI, Anthropic, Gemini 멀티 LLM 라우팅 및 의료법 금기어 치환 파이프라인
* `clipboard_manager.py`: OS 크로스플랫폼 (macOS / Windows) HTML 클립보드 인젝터
* `naver_publisher.py`: Playwright persistent context 기반 네이버 스마트에디터 전송기
* `config.json`: 동적 LLM 키, 페르소나, 팩트 DB, SEO 키워드 & 의료법 치환 단어장
* `AGENTS.md`: Vibe Coding 마스터 규약

## 🛡️ 기술적 특징

1. **안티 봇 & CAPTCHA 우회**: `Playwright persistent user context`로 사용자의 크롬 로그인 세션을 유지하여 봇 감지를 무력화합니다.
2. **서식 깨짐 방지**: 스마트에디터 DOM 스트리핑 현상을 막기 위해 OS 클립보드 레벨에서 HTML 포맷을 바인딩하고 `Ctrl+V` / `Cmd+V` 이벤트를 발생시킵니다.
3. **의료법 리스크 제로**: `탈모 완치`, `모발 영구 재생` 등 금기어가 포함될 경우 `두피 보완`, `스타일 개선` 등의 안전 용어로 자동 치환(Sanitization)됩니다.
